---

### 核心诊断框架：4 类高张力对白

修复前先判定当前对白属于哪一类，不同类别的压力来源和刀口落点不同。

1. **地位压迫型**：权力/身份/资源差距产生的压力（命令、否定、威胁、沉默惩罚）
2. **情感绑架型**：利用情感关系迫使对方就范（愧疚、恩情、以爱为名的控制）
3. **利益摊牌型**：明确的利益冲突或谈判，筹码清晰，局面必须变化
4. **冷静判决型**：掌握真相/证据/道德高地，以不容置疑的态度做出裁决

### 对白检查清单

- [ ] 这段对白属于哪一类高张力对白？（地位压迫 / 情感绑架 / 利益摊牌 / 冷静判决）
- [ ] 这段对白下方有压力吗？压力来源是否清晰？
- [ ] 刀口句是哪一句？删掉它，整段还有没有张力？
- [ ] 换个人能说出同样的话吗？（检验人物声音独特性）
- [ ] 这段对白在告诉读者已知信息吗？（禁止说明书式对白）
- [ ] 每句都有存在的必要吗？（删除无意义寒暄）
- [ ] 沉默和动作被利用了吗？
