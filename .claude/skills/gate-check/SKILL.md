当此技能被调用时：

1. **确定阶段**：读取参数或检测当前阶段。
2. **读取阶段产出**。
3. **运行审查**。
4. **给出 verdict**。

---

### 阶段门定义

参见 `.claude/docs/director-gates.md`。

| 阶段 | 审查门 | 审查内容 | 方法论判据 |
|------|--------|---------|-----------|
| 概念确立 | CD-CONCEPT | 题材、hook、premise、故事引擎 | 故事引擎类型清晰（升级/调查/身份反打/关系拉扯/倒计时逼迫）；最小产物6件套完整；卖点不埋在后段 |
| 结构设计 | CD-STRUCTURE | 世界观、人物、总大纲、分卷大纲 | 卷四件套（卷目标/核心冲突/卷高潮/卷末变化）；主角+至少1个关键配角/反派档案完整 |
| 写作准备 | PR-SETUP | 章纲模板、风格指南 | 前3章章纲（黄金三章）完成；章四件套（目标/冲突/新信息/章末拉力）每章都有 |
| 开篇试写 | CD-OPENING | 黄金三章、开篇吸引力 | 字数硬指标：前300-500字有抓手；前1500-3000字呈现卖点；前6000字完成五个亮相 |
| 批量生产 | PR-MILESTONE | 逐章质量、里程碑达成 | 六种一致性审查通过；5层因果链无断裂；5维人物状态连续 |
| 精修打磨 | CD-POLISH | 全稿一致性、去AI味 | 5类AI味自查通过；任意两项不稳必须回专项模块修复 |
| 发布交付 | CD-RELEASE | 最终审查、导出格式 | 全稿六种一致性复查；长线伏笔回收；人物弧光完成度 |

---

### Verdict

```
[门控ID]: 通过
```
或
```
[门控ID]: 有条件通过
```
或
```
[门控ID]: 不通过
```

---

### 裁决后

- **通过**：允许进入下一阶段
- **有条件通过**：允许进入，但需跟踪未解决问题
- **不通过**：必须修复问题后才能进入下一阶段
