当此技能被调用时：

1. **读取上下文**：读取 `design/novel/concept.md`、人物档案、世界观。
2. **设计分卷结构**：确定全书的分卷规划。
3. **设计章纲**：至少完成第一卷前10-20章的章纲。
4. **运行内容密度自检**：逐章检查场景拆分、字数预估、薄章判定（见下方"字数与内容密度"一节）。
5. **呈现薄章选项**：若发现薄章，通过 `AskUserQuestion` 让用户选择补充、合并或保持。

---

### 分卷设计

每卷必须包含：
- 卷目标
- 卷核心冲突
- 卷高潮
- 卷末变化

### 黄金三章

前三章必须完成五个亮相：
- 主角亮相
- 卖点亮相
- 第一冲突亮相
- 阶段目标亮相
- 追更理由亮相

**字数硬指标**：前300-500字有抓手；前1500-3000字呈现卖点；前6000字让读者知道主角是谁、遇到什么、卖点是什么、接下来想看什么。

### 章四件套（每章章纲必备）

- 本章目标：主角这章想做什么
- 本章冲突：谁/什么阻止他
- 本章新信息：读者/主角新知道了什么
- 本章章末拉力：为什么读者还要往下看（落点类型：余韵 / 反打一刀 / 判决 / 轻喜回钩）

### 前10章最小计划

规划前10章时必须回答：
1. 第一卷最核心要解决什么？
2. 最强冲突是谁或什么？
3. 卷末局面必须怎样变化？
4. 前10章里至少哪三次升级或反打不能缺？
5. 哪几章最容易水，提前怎么防？

### 字数与内容密度（防"章纲空洞"）

**这是最容易在生产阶段翻车的问题**：章纲看起来四件套齐全、结构合理，但实际内容量根本撑不到目标字数。写的时候才发现没什么可写——因为章纲只有骨架没有肉。

**每章章纲必须包含场景拆分**，场景数至少 3 个（收束/高潮章除外，但必须标注"本章仅 N 个场景"且给出理由）：

| 场景 | 地点 | 人物 | 目标 | 变化 | 字数预估 |
|------|------|------|------|------|---------|
| 场景1 | | | | | 500-800 |
| 场景2 | | | | | 500-800 |
| 场景3 | | | | | 500-800 |
| ... | | | | | |

**内容密度自检**：

1. **场景字数总和**：各场景字数预估之和 必须 ≥ 目标字数的 60%（余下的 40% 是描写、过渡、内心活动——这些不单独占场景但消耗字数）。如果场景预估总和不到目标的 60%，说明章纲太薄。
2. **场景数量经验值**：
   - 3000 字章：至少 3-4 个场景
   - 4000 字章：至少 4-6 个场景
   - 低于 3 个场景的章（非收束章）：高度可疑，很可能写不够字数
3. **"无变化场景"检测**：每个场景必须有状态变化（谁知道了什么 / 做了什么决定 / 关系发生了什么改变）。如果一个场景的"变化"列是空的或与"目标"列雷同——那个场景是死的，删除或重写。

**薄章判定标准**：

| 情况 | 判定 | 建议动作 |
|------|------|---------|
| 场景数 < 3 且非收束/高潮章 | 薄章 | 补充场景或并入相邻章 |
| 场景字数总和 < 目标字数 50% | 薄章 | 补充场景或拆入相邻章 |
| 场景数 ≥ 3 但每个场景字数 < 300 | 碎片章 | 合并场景，减少场景数但增加每场景深度 |
| 连续 2+ 章判定为薄章 | 结构问题 | 优先考虑合并章节而非各自补充 |

### 薄章处理流程

章纲生成完成后，逐章运行内容密度自检。如果发现薄章：

1. **列出所有薄章**（章号 + 薄章原因 + 当前场景数）
2. **通过 `AskUserQuestion` 呈现选项**：
   - **补充内容**：为该章增加 1-2 个有变化的场景，使场景总数和字数预估达标
   - **合并章节**：将该章与相邻章合并（合并后章纲重新四件套），总章数减 1
   - **保持现状**：用户确认该章内容确实只需要这么多（如：收束章、纯情感章、风格化短章）
3. **执行用户选择**，更新章纲文件和大纲章纲表

**注意**：不要为了凑场景数而生造"走过场"场景。每个场景必须有独立的存在理由——读者通过这个场景知道了上一个场景不知道的东西。如果实在想不出有意义的场景，那就是合并的信号。

### 章纲自查清单（生成后必查）

在生成所有章纲后、写入文件前，逐项检查：

- [ ] 每章有场景拆分（≥3 场景，收束/高潮章除外）
- [ ] 每个场景有独立变化（不是"目标"的重复）
- [ ] 场景字数总和 ≥ 目标字数 60%
- [ ] 薄章已标记并呈现给用户决策
- [ ] 无"走过场"场景（变化为空或与目标雷同的场景）
- [ ] 章末拉力类型没有连续 2 章重复
- [ ] 每章的新信息与上一章有实质不同（不重复暗示同一件事）
