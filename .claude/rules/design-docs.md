# 设计文档规则

## 通用规则

- 所有设定必须与剧情推进强相关
- 禁止纯展示性设定（只为世界观宏大而设定，与剧情无关）
- 设计文档的变更必须通过审查才能同步到正文
- 正文不得反向修改设计文档

## 人物档案规则

- 每个人物档案必须包含：目标、阻碍、变化
- 人物目标必须与剧情冲突强相关
- 人物变化必须有清晰的触发事件和过程

## 世界观规则

- 世界规则必须标注 Canon Level（核心/重要/次要）
- 核心规则全书不可违背
- 重要规则大部分适用，例外需明确解释
- 次要规则可灵活调整

## 变更管理

- 设计文档变更时，必须评估对已有正文的影响
- 重大变更（核心规则、人物目标）需要重新审查相关章节
- 变更记录必须写入文档的"变更历史"部分
