# 生产管理规则

## session-state/active.md

- 必须保持最新，每次关键操作后更新
- 必须包含：当前阶段、当前卷/章、状态、待解决问题
- 压缩前必须确认已更新

## 审查记录

- 每次审查必须生成审查记录
- 审查记录必须关联具体章节
- 审查记录必须包含：verdict、发现问题、修复状态

## 里程碑

- 里程碑必须有可测试的成功标准
- 里程碑必须包含章节清单
- 里程碑必须包含质量门检查点

## 冲刺计划

- 冲刺必须有明确的目标和成功标准
- 冲刺必须包含章节任务清单
- 冲刺必须有风险与应对措施

## 审查模式

- 审查模式由 `production/review-mode.txt` 控制
- 可以在任何时候切换审查模式
- 切换审查模式不需要审批，但需要记录原因

## 文件管理

- `session-state/` 和 `session-logs/` 不提交到 git
- 审查记录必须提交到 git
- 冲刺计划和里程碑必须提交到 git
