# 大纲规则

## 章纲规则

每章章纲必须包含：
- 本章目标
- 本章冲突
- 本章新信息
- 本章章末拉力

缺少任意一项的章纲不合格。

**每章章纲必须包含场景拆分**（≥3 个场景，收束/高潮章除外且须标注原因），每个场景包含地点、人物、目标、变化、字数预估。各场景字数预估之和 必须 ≥ 目标字数的 60%。缺少场景拆分的章纲视为内容密度不足。

## 薄章检测与处理

创建和审查章纲时必须检查内容密度：

| 情况 | 判定 | 建议动作 |
|------|------|---------|
| 场景数 < 3 且非收束/高潮章 | 薄章 | 补充场景或并入相邻章 |
| 场景字数总和 < 目标字数 50% | 薄章 | 补充场景或拆入相邻章 |
| 场景数 ≥ 3 但每个场景字数 < 300 | 碎片章 | 合并场景，减少场景数但增加每场景深度 |
| 连续 2+ 章判定为薄章 | 结构问题 | 优先考虑合并章节而非各自补充 |
| 全卷≥30% 章为薄章 | 系统性密度不足 | 重新评估总章数 |

发现薄章后必须通过 AskUserQuestion 让用户选择：补充内容 / 合并章节 / 保持现状。不要为了凑场景数而生造"走过场"场景。

## 分卷大纲规则

每卷大纲必须包含：
- 卷目标
- 卷核心冲突
- 卷高潮
- 卷末变化

## 伏笔管理

- 伏笔必须有计划回收标记
- 每个伏笔必须标注：铺设章节、计划回收章节、回收方式
- 禁止无计划回收的伏笔（除非明确标注为"可能不回收"）

## 禁止"过渡章"

- 禁止无事件、无冲突、无变化的"过渡章"
- 必须推进的剧情可以通过合并到相邻章节来实现
- 时间跳跃必须通过锚点呈现，不要用一整章"过渡"

## 大纲与正文的对应

- 正文必须遵循大纲的方向（目标、冲突）
- 正文可以在细节上与大纲不同，但核心方向不能偏离
- 重大偏离（人物目标改变、冲突性质改变）必须更新大纲

## 变更管理

- 大纲变更时，必须评估对后续章节的影响
- 重大结构变更需要重新审查相关卷的大纲
- 变更记录必须写入文档的"变更历史"部分
