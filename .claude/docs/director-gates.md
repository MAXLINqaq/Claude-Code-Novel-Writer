# 总监审查门定义

## CD-CONCEPT — 概念确立门

**审查者**: creative-director, genre-specialist

**通过标准**:
- [ ] 小说概念文档 `design/novel/concept.md` 已创建
- [ ] 包含：题材、消费点、hook、premise、故事引擎、目标长度
- [ ] 核心支柱文档 `design/novel/pillars.md` 已创建
- [ ] 支柱之间有明确的设计测试
- [ ] 题材诊断清晰：知道读者为什么来看这本书
- [ ] 故事引擎能跑过前10-20章

**不通过常见原因**:
- 概念过于模糊，无法落地为具体情节
- 消费点不明确，不知道读者为什么付费
- 故事引擎只能撑3-5章，缺乏持续性
- 题材与平台不匹配

---

## CD-STRUCTURE — 结构设计门

**审查者**: story-architect, creative-director

**通过标准**:
- [ ] 世界观圣经 `design/novel/worldbuilding/rules.md` 已创建
- [ ] 主角档案 `design/novel/characters/protagonist.md` 完整
- [ ] 至少1个关键配角/反派档案已创建
- [ ] 总大纲 `outlines/master-outline.md` 已创建（至少包含第一卷）
- [ ] 第一卷大纲 `outlines/volume-01-outline.md` 已创建
- [ ] 卷目标、卷核心冲突、卷高潮、卷末变化明确
- [ ] 前10章章纲已完成，每章含目标/冲突/新信息/章末拉力

**不通过常见原因**:
- 世界观规则有内在矛盾
- 人物目标与剧情冲突不匹配
- 分卷结构不合理（太短/太长/无高潮）
- 章纲过于笼统，无法指导写作

---

## PR-SETUP — 写作准备门

**审查者**: production-editor

**通过标准**:
- [ ] 前3章章纲 `outlines/chapter-outlines/vol01-chapter-00*.md` 已完成
- [ ] 风格指南已确定（叙事视角、时态、语感）
- [ ] 审查模式已设定（full/lean/solo）
- [ ] 写作环境就绪

---

## CD-OPENING — 开篇门

**审查者**: creative-director, opening-specialist

**通过标准**:
- [ ] 第一章 `manuscript/volume-01/chapter-001.md` 已完成
- [ ] 前300-500字有抓手
- [ ] 前1500-3000字呈现卖点
- [ ] 主角身份/处境清晰
- [ ] 异常局面已建立
- [ ] 第二章、第三章已完成
- [ ] 黄金三章完成：主角亮相、卖点亮相、第一冲突亮相、阶段目标亮相、追更理由亮相
- [ ] 读者知道：主角是谁、遇到什么、卖点是什么、接下来想看什么

**不通过常见原因**:
- 开篇节奏过慢，前1000字无冲突
- 主角形象模糊，读者无法代入
- 卖点隐藏太深，读者不知道这本书有什么特别
- 黄金三章后读者没有理由继续看下去

---

## PR-MILESTONE — 生产里程碑门

**审查者**: production-editor, story-architect

**通过标准**:
- [ ] 当前卷的目标进度达成
- [ ] 已完成章节的质量达标（审查通过）
- [ ] 人物弧光按预期推进
- [ ] 伏笔按计划铺设
- [ ] 节奏曲线符合设计（张弛有度）

**检查频率**: 每完成一卷或每完成10章

---

## CD-POLISH — 精修门

**审查者**: creative-director, style-director

**通过标准**:
- [ ] 全稿去AI味检查通过
- [ ] 六种一致性复查通过
- [ ] 文风统一（对话风格、叙事腔调一致）
- [ ] 节奏优化完成（无冗余场景、无信息堆积）
- [ ] 长线伏笔已回收或明确标注回收计划
- [ ] 人物弧光完整

---

## CD-RELEASE — 发布门

**审查者**: creative-director, production-editor

**通过标准**:
- [ ] 全稿无遗留审查问题
- [ ] 导出格式正确
- [ ] 简介/标签/分类已准备
- [ ] 作者有话要说（可选）
