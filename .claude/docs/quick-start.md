# 快速开始

## 5 分钟上手

### 1. 初始化项目

在 Claude Code 中打开仓库后，运行：

```
/start
```

这会检测当前项目状态并引导你进入正确的起点。

### 2. 从零开始创作

如果还没有小说概念：

```
/brainstorm [你的简介或点子]
```

然后：

```
/concept-plan
```

### 3. 已有概念，需要大纲

```
/volume-outline
```

### 4. 开始写作

```
/write-chapter [卷号] [章号]
```

例如：

```
/write-chapter 1 1
```

### 5. 审查章节

```
/review-chapter manuscript/volume-01/chapter-001.md
```

## 常用技能速查

| 你想做什么 | 使用 |
|-----------|------|
| 开始新项目 | `/start` |
| 脑暴创意 | `/brainstorm` |
| 规划概念 | `/concept-plan` |
| 设计分卷大纲 | `/volume-outline` |
| 写开篇 | `/opening` |
| 写章节 | `/write-chapter` |
| 审查章节 | `/review-chapter` |
| 精修章节 | `/polish-chapter` |
| 修复剧情逻辑 | `/revise-plot` |
| 修复人物一致性 | `/revise-character` |
| 检测项目状态 | `/project-stage-detect` |
| 查看帮助 | `/help` |

## 目录速查

| 目录 | 用途 |
|------|------|
| `design/novel/` | 小说设计（概念、世界观、人物） |
| `outlines/` | 大纲（总大纲、分卷、章纲） |
| `manuscript/` | 正文（按卷分目录） |
| `production/` | 生产管理（冲刺、里程碑、审查） |
